# เตรียมงานตั้งเวลา

อ่าน docs/scheduling.md แล้วเตรียมงานอัปเดต [Dashboard] เวลา [เวลา] เขตเวลา Asia/Bangkok ความถี่ [ความถี่]
ระบุว่าจะได้ไฟล์ข้อมูลใหม่จากที่ใด เครื่องใดรัน และบันทึกผลที่ใด อย่าสมมติว่า OAuth ของแอปพร้อมใช้ใน GitHub Actions
รันทดสอบหนึ่งรอบก่อน: ตรวจข้อมูลใหม่ ใช้สูตรเดิม คงข้อมูลเดิมเมื่อผิดพลาด และแจ้งเมื่อมีข้อมูลใหม่หรือปัญหา
แสดงคำสั่งและตารางเวลาจริงให้ตรวจ แล้วรอการอนุญาตเปิดงานตั้งเวลา
