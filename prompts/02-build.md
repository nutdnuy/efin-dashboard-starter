# สร้างหรือปรับ Dashboard

ใช้ repo นี้สร้าง Dashboard สำหรับ [เป้าหมายผู้ใช้] โดยติดตาม [รายชื่อหุ้น] เทียบ [Benchmark] จาก [แหล่งข้อมูล]
ปรับ BRIEF.md และ dashboard.config.json ให้ตรงโจทย์ เก็บวิธีคำนวณที่ตรวจสอบได้ และแสดงแหล่งข้อมูล วันที่ล่าสุด และข้อมูลที่ขาด
ทำส่วนที่ใช้งานได้จริงทีละขั้น รักษาโครงที่มีอยู่ ใช้สกิลที่ติดตั้งและเหมาะกับงานตามข้อกำหนดการเรียก
ห้ามสร้างตัวเลขหรือ API ขึ้นเอง ถ้ายังไม่มีข้อมูลจริงให้ใช้เดโมที่ระบุว่าเป็นข้อมูลจำลอง
ส่งผลลัพธ์ที่เปิดได้ พร้อมผลตรวจและข้อจำกัด
