# Efin Dashboard Starter

**คุยกับ AI จนได้ Dashboard การลงทุนที่คุณอยากใช้จริง**

ชุดเริ่มต้นสำหรับคลาส Efin รวม Skills ของ [Matt Pocock](https://github.com/mattpocock/skills) ไว้ให้เลือกใช้ ตั้งแต่ช่วยถามโจทย์ ออกแบบ วางแผน สร้าง ไปจนถึงปรับงานจากสิ่งที่คุณลองใช้จริง คุณเลือกได้เองว่าจะติดตามหุ้นไทย พอร์ต กองทุน หรือสินทรัพย์อื่น และอยากให้หน้าจอช่วยตัดสินใจเรื่องอะไร

**คุยโจทย์ → เห็นแบบ → เลือก → สร้าง → ลองใช้ → ปรับจนถูกใจ**

[สร้างโปรเจกต์ของตัวเอง](https://github.com/nutdnuy/efin-dashboard-starter/generate) · [เริ่มคุย](START.md) · [คู่มือคลาส](docs/class-guide.md) · [Flow](docs/workflow.md)

## เริ่มได้ใน 3 ขั้น

1. กด **Use this template → Create a new repository** แล้ว Clone repo ของตัวเอง หรือกด **Code → Download ZIP** และแตกไฟล์
2. เปิดโฟลเดอร์โปรเจกต์ในแอป Agent ที่อ่านและแก้ไฟล์ รวมถึงรันโค้ดได้
3. วางข้อความนี้ในแชต:

```text
อ่าน START.md และ AGENTS.md แล้วใช้สกิล grill-with-docs จาก .agents/skills/grill-with-docs/SKILL.md ช่วยฉันออกแบบ Dashboard การลงทุน เริ่มจากถามว่าฉันอยากใช้หน้า Dashboard ช่วยตัดสินใจเรื่องอะไร คุยทีละประเด็นและจดข้อสรุปใน BRIEF.md
```

ยังไม่ต้องเลือก framework ติดตั้ง Node.js หรือเตรียม CSV ให้เริ่มจากโจทย์ของคุณก่อน แล้วให้ Agent เสนอเครื่องมือและข้อมูลที่เหมาะกับแบบที่เลือก

แชตบนเว็บไซต์ทั่วไปไม่ได้เห็นไฟล์ใน repo หรือรันโปรเจกต์บนเครื่องให้โดยอัตโนมัติ ต้องเปิดโฟลเดอร์ผ่านแอป Agent ที่มีความสามารถเหล่านี้ หรือเชื่อมต่อเครื่องมือที่จำเป็นก่อน

## คุยอะไรกับ Agent ได้บ้าง

เริ่มจากเรื่องที่อยากรู้ ไม่จำเป็นต้องมีสเปกครบ เช่น:

> “ฉันมีหุ้นไทย 10 ตัว อยากเปิดหน้าเดียวแล้วรู้ว่าพอร์ตกระจุกตัวตรงไหน”
>
> “ฉันอยากเทียบหุ้นใน watchlist กับ SET แล้วเลือกช่วงเวลาเองได้”
>
> “อยากได้หน้าสรุปที่เปิดดูตอนเช้า ใช้สีเรียบ ๆ ตัวเลขใหญ่ และดูบนมือถือได้”

หลังคุยจนเห็นภาพ ลองสั่งว่า **“เสนอหน้าตา 2 แบบพร้อมข้อมูลตัวอย่าง ให้ฉันเลือกและบอกสิ่งที่ชอบ”** แล้วปรับจากภาพหรือแบบร่างที่เห็นจริง Agent จะเก็บข้อสรุปใน [BRIEF.md](BRIEF.md) เพื่อให้การสร้างและแก้ครั้งต่อไปต่อเนื่องกัน

เมื่อพร้อมสร้าง ให้คุณเรียก Skills ตามขั้นที่ต้องการ:

```text
ใช้สกิล to-spec สรุป Dashboard ที่คุยกันและแบบที่ฉันเลือกเป็นสเปก
ใช้ brief และรูปแบบการเก็บงานใน AGENTS.md ระบุด้วยว่าจะตรวจผลอย่างไร
```

จากนั้น:

```text
ใช้สกิล implement สร้าง Dashboard จากสเปกนี้ให้เปิดลองใช้ได้
เลือกเครื่องมือให้เหมาะกับงาน ตรวจฟังก์ชันและตัวเลขที่ใช้จริง
แล้วเปิดหน้าตัวอย่างให้ฉันดู พร้อมบอกสิ่งที่ยังทำไม่ได้
```

ถ้าหน้าจอยังไม่ถูกใจ บอกสิ่งที่เห็นและสิ่งที่ต้องการ เช่น **“ตารางแน่นไป เก็บไว้ 5 คอลัมน์ ย้ายสัดส่วนพอร์ตขึ้นบน แล้วเปิดให้ดูใหม่”** หรือ **“เพิ่มวิธีตรวจว่าผลตอบแทนนี้คำนวณจากวันไหนถึงวันไหน”** ทำเป็นรอบสั้น ๆ จนใช้งานได้ตามโจทย์

## Skills ที่มีให้เลือก

Skills หลัก 11 ตัวนี้คัดลอกจาก upstream โดยเก็บเนื้อหาต้นฉบับไว้ พร้อมสกิลประกอบที่จำเป็น คุณไม่ต้องใช้ทุกตัวในหนึ่งงาน

| ใช้เมื่อ | Skill | ช่วยอะไร |
|---|---|---|
| เริ่มคุย | [ask-matt](.agents/skills/ask-matt/SKILL.md) | ช่วยเลือกสกิลหรือขั้นตอนที่เหมาะกับสถานการณ์ |
| เริ่มคุย | [grill-with-docs](.agents/skills/grill-with-docs/SKILL.md) | ถามให้โจทย์ชัด และบันทึกคำศัพท์กับเหตุผลของการตัดสินใจ |
| เตรียมโปรเจกต์ | [setup-matt-pocock-skills](.agents/skills/setup-matt-pocock-skills/SKILL.md) | ตั้งค่าบริบทโปรเจกต์ให้ชุดสกิลวิศวกรรมใช้งานร่วมกันได้ |
| พร้อมสร้าง | [to-spec](.agents/skills/to-spec/SKILL.md) | สรุปบทสนทนาที่ตกลงกันแล้วเป็นสเปก |
| พร้อมสร้าง | [implement](.agents/skills/implement/SKILL.md) | สร้างงานตามสเปก พร้อมทดสอบและตรวจโค้ด |
| งานใหญ่ขึ้น | [to-tickets](.agents/skills/to-tickets/SKILL.md) | แบ่งแผนเป็นงานย่อยและระบุว่างานใดต้องรอกัน |
| งานใหญ่ขึ้น | [implement-spec](.agents/skills/implement-spec/SKILL.md) | ทำสเปกที่แบ่งเป็นหลายงานบน integration branch เดียว |
| งานใหญ่ขึ้น | [wayfinder](.agents/skills/wayfinder/SKILL.md) | วางทางไปต่อสำหรับงานใหญ่ที่ต้องทำหลายรอบ |
| ดูแลงานต่อ | [triage](.agents/skills/triage/SKILL.md) | จัดการ issue ตามสถานะและบทบาท |
| ดูแลงานต่อ | [improve-codebase-architecture](.agents/skills/improve-codebase-architecture/SKILL.md) | สำรวจโค้ดและช่วยเลือกจุดปรับโครงสร้าง |
| ดูแลงานต่อ | [retro](.agents/skills/retro/SKILL.md) | ทบทวนวิธีทำงานและเสนอสิ่งที่ควรปรับในสภาพแวดล้อม Agent |

หากแอปรองรับ ใช้ชื่อแบบ `/grill-with-docs`, `/to-spec` หรือ `/implement` ได้ หากไม่พบคำสั่ง ให้บอก Agent อ่านไฟล์ `.agents/skills/<ชื่อสกิล>/SKILL.md` แล้วใช้สกิลนั้นโดยตรง วิธีเรียกขึ้นอยู่กับแอป สกิลที่ต้องให้ผู้ใช้เรียกจะไม่ทำงานต่อกันอัตโนมัติเพียงเพราะอยู่ใน Flow

การ Clone repo นี้นำ Skills มาไว้ในโปรเจกต์ ไม่ได้ติดตั้งหรือแก้ Skills ส่วนกลางในเครื่อง หากติดตั้งชุด Matt ไว้อยู่แล้ว สามารถใช้ชุดนั้นได้โดยระบุให้ Agent ชัดเจนว่าจะใช้สำเนาใด ดู[คู่มือ Skills](docs/skills.md)
