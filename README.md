# Efin Dashboard Starter

**คุยกับ AI จนได้ Dashboard การลงทุนที่คุณอยากใช้จริง**

ชุดเริ่มต้นสำหรับคลาส Efin ใช้ Skills ที่ดัดแปลงจาก [Matt Pocock](https://github.com/mattpocock/skills) ให้เรียกง่ายและทำงานต่อเนื่อง ตั้งแต่ช่วยถามโจทย์ ออกแบบ สร้าง ไปจนถึงปรับงานจากสิ่งที่คุณลองใช้จริง คุณเลือกได้เองว่าจะติดตามหุ้นไทย พอร์ต กองทุน หรือสินทรัพย์อื่น และอยากให้หน้าจอช่วยตัดสินใจเรื่องอะไร

**คุยโจทย์ → เห็นแบบ → เลือก → สร้าง → ลองใช้ → ปรับจนถูกใจ**

[สร้างโปรเจกต์ของตัวเอง](https://github.com/nutdnuy/efin-dashboard-starter/generate) · [เริ่มคุย](START.md) · [คู่มือคลาส](docs/class-guide.md) · [Flow](docs/workflow.md)

## เริ่มได้ใน 3 ขั้น

1. กด **Use this template → Create a new repository** แล้ว Clone repo ของตัวเอง หรือกด **Code → Download ZIP** และแตกไฟล์
2. เปิดโฟลเดอร์โปรเจกต์ในแอป Agent ที่อ่านและแก้ไฟล์ รวมถึงรันโค้ดได้
3. วางข้อความนี้ในแชต:

```text
อ่าน START.md และ AGENTS.md แล้วใช้สกิล plan-dashboard จาก .agents/skills/plan-dashboard/SKILL.md ช่วยฉันออกแบบ Dashboard การลงทุน เริ่มจากถามว่าฉันอยากใช้หน้า Dashboard ช่วยตัดสินใจเรื่องอะไร คุยทีละประเด็นและจดข้อสรุปใน BRIEF.md
```

ยังไม่ต้องเลือก framework ติดตั้ง Node.js หรือเตรียม CSV ให้เริ่มจากโจทย์ของคุณก่อน แล้วให้ Agent เสนอเครื่องมือและข้อมูลที่เหมาะกับแบบที่เลือก

แชตบนเว็บไซต์ทั่วไปไม่ได้เห็นไฟล์ใน repo หรือรันโปรเจกต์บนเครื่องให้โดยอัตโนมัติ ต้องเปิดโฟลเดอร์ผ่านแอป Agent ที่มีความสามารถเหล่านี้ หรือเชื่อมต่อเครื่องมือที่จำเป็นก่อน

## คุยอะไรกับ Agent ได้บ้าง

เริ่มจากเรื่องที่อยากรู้ ไม่จำเป็นต้องมีสเปกครบ เช่น:

> “ฉันมีหุ้นไทย 10 ตัว อยากเปิดหน้าเดียวแล้วรู้ว่าพอร์ตกระจุกตัวตรงไหน”
>
> “ฉันอยากเทียบหุ้นใน watchlist กับ SET แล้วเลือกช่วงเวลาเองได้”
>
> “อยากได้หน้าสรุปที่เปิดดูตอนเช้า ใช้สีเรียบ ๆ ตัวเลขใหญ่ และดูบนมือถือได้”

หลังคุยจนเห็นภาพ ลองสั่งว่า **“เสนอหน้าตา 2 แบบพร้อมข้อมูลตัวอย่าง ให้ฉันเลือกและบอกสิ่งที่ชอบ”** แล้วปรับจากภาพหรือแบบร่างที่เห็นจริง Agent จะเก็บข้อสรุปใน [BRIEF.md](BRIEF.md) เพื่อให้การสร้างและแก้ครั้งต่อไปต่อเนื่องกัน

เมื่อเลือกแบบแล้ว สั่งสั้น ๆ ได้เลย:

```text
ใช้ build-dashboard สร้างจากแบบที่เลือก แล้วเปิดให้ลอง
```

`build-dashboard` รวมงานสรุปสเปก วางแผน แบ่งงาน สร้าง ตรวจ และปรับปรุงไว้ในคำสั่งเดียว Agent จะเลือกขั้นตอนเท่าที่งานต้องใช้ ตรวจฟังก์ชันและตัวเลข แล้วเปิดให้คุณลอง โดยยังยึดแบบและขอบเขตที่คุณเลือก

ถ้าหน้าจอยังไม่ถูกใจ บอกสิ่งที่เห็นและสิ่งที่ต้องการ เช่น **“ตารางแน่นไป เก็บไว้ 5 คอลัมน์ ย้ายสัดส่วนพอร์ตขึ้นบน แล้วเปิดให้ดูใหม่”** หรือ **“เพิ่มวิธีตรวจว่าผลตอบแทนนี้คำนวณจากวันไหนถึงวันไหน”** ทำเป็นรอบสั้น ๆ จนใช้งานได้ตามโจทย์

## จำแค่ 4 ตัวช่วย

| ตัวช่วย | คำสั่ง | ใช้เมื่อ |
|---|---|---|
| เลือกตัวช่วย | [choose-skill](.agents/skills/choose-skill/SKILL.md) | ยังไม่แน่ใจว่าจะเริ่มหรือไปต่ออย่างไร |
| คุยออกแบบ Dashboard | [plan-dashboard](.agents/skills/plan-dashboard/SKILL.md) | อยากให้ช่วยถามโจทย์ เสนอแบบ และจดสิ่งที่เลือก |
| สร้างและปรับ Dashboard | [build-dashboard](.agents/skills/build-dashboard/SKILL.md) | พร้อมสร้าง หรืออยากแก้จากหน้าที่ลองใช้แล้ว |
| ตั้งค่าโปรเจกต์ | [setup-project](.agents/skills/setup-project/SKILL.md) | ต้องเตรียมหรือปรับบริบทโปรเจกต์ให้ตัวช่วยทำงานร่วมกัน |

เบื้องหลังมีสกิลประกอบสำหรับถามคำถาม ทำแบบตัวอย่าง ค้นข้อมูล ออกแบบโค้ด ทดสอบ และตรวจงาน ซึ่งมีชื่อกับคำอธิบายภาษาไทยให้ค้นหาได้ คุณเริ่มจาก `plan-dashboard` แล้วใช้ `build-dashboard` สร้างและปรับต่อได้โดยไม่ต้องจำคำสั่งแต่ละขั้น ดูรายละเอียดและชื่อที่เปลี่ยนใน[คู่มือ Skills](docs/skills.md)

หากแอปรองรับ ใช้ `/plan-dashboard` หรือ `/build-dashboard` ได้ หากไม่พบคำสั่ง ให้บอก Agent อ่านไฟล์ `.agents/skills/<ชื่อสกิล>/SKILL.md` แล้วใช้สกิลนั้นโดยตรง วิธีเรียกขึ้นอยู่กับแอป

การ Clone repo นี้นำ Skills มาไว้ในโปรเจกต์ ไม่ได้ติดตั้งหรือแก้ Skills ส่วนกลางในเครื่อง หากมีชุด Matt เดิมอยู่แล้ว ให้ระบุว่าจะใช้ชุดของคลาสในโฟลเดอร์นี้ เพื่อให้ชื่อและขั้นตอนตรงกับคู่มือ
