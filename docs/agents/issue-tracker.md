# Issue tracker

Class default: local Markdown files in .scratch/<feature>/ (gitignored).
Each issue includes goal, acceptance criteria, data source, dependencies and verification evidence. Create a spec only when it helps the requested change.
GitHub is optional. When a learner explicitly chooses it, resolve their own current origin with git remote -v; never hard-code the instructor repository as a write destination.
PRs as a request surface: off.
Do not create issues, PR comments or external messages without the human's authorization for that action.
