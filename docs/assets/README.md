# README journey illustration

- [PNG](dashboard-journey.png): README image, 2400 × 1488 pixels.
- [SVG](dashboard-journey.svg): scalable preview with accessible title and description.
- [Excalidraw source](dashboard-journey.excalidraw): editable shapes, text and connectors.

The three stages represent the starter's documented workflow: plan-dashboard,
learner choice, then build-dashboard and feedback. The miniature layouts are
concept illustrations, not screenshots or market data.

Created with the Excalidraw skill using editable scene primitives and a matching
native SVG export. No Image Generator was used. The visual uses the SprintAI
course palette (navy, orange, paper), with no logo or third-party icon assets.
Original artwork is covered by the repository MIT license.

Validation: scene validator passed; Thai text and connector layout were visually
inspected. The local README preview was checked at 1100px and 390px: image loads,
alt text is present, and there is no page-level horizontal overflow. The local
preview approximates GitHub styling; it is not an assertion of identical fonts
across all devices.
