# รายการตรวจรับ Dashboard

ใช้รายการนี้ก่อนจบแบบฝึกหัดหรือแชร์โปรเจกต์ ทำเครื่องหมายเฉพาะข้อที่ตรวจจริง พร้อมเก็บคำสั่ง ผลลัพธ์ หรือภาพหน้าจอที่เกี่ยวข้อง

## เปิดและใช้งาน

- [ ] ใช้ Node.js 22+ และเปิด `http://localhost:3100` ด้วย `npm start` ได้
- [ ] เปิดข้อมูลจำลองได้โดยไม่ต้องติดตั้ง dependencies หรือมี API key
- [ ] เห็นชัดว่า DEMO_BANK, DEMO_ENERGY, DEMO_TECH และ DEMO_SET เป็นข้อมูลสังเคราะห์
- [ ] เลือกหุ้นและช่วงข้อมูลแล้วกราฟ ตาราง และสถานะเปลี่ยนสอดคล้องกัน
- [ ] ข้อความสำคัญอ่านได้บนจอที่ใช้สอน และไม่ถูกตัดเมื่อหน้าต่างแคบ

## ความหมายของข้อมูล

- [ ] รหัสหุ้นและ benchmark ตรงกับไฟล์และ config
- [ ] แยกวันที่ข้อมูลล่าสุดออกจากเวลาที่นำเข้า
- [ ] หุ้นที่ไม่มีราคาตรงวันล่าสุดของ benchmark แสดงปัญหาข้อมูล ไม่ใช้ค่าที่เก่ากว่าแทนเงียบๆ
- [ ] วันที่ขาดไม่ถูกเติมราคา และ lookback ใช้จำนวนช่วงข้อมูลร่วมกันจริง
- [ ] ข้อมูลไม่พอสำหรับ lookback แสดงสถานะคำนวณไม่ได้ ไม่แสดงผลเป็นศูนย์
- [ ] ตรวจตัวอย่างหุ้น +10%, benchmark +5% แล้ว excess return เป็น 5 percentage points
- [ ] กราฟราคา rebase หุ้นและ benchmark ให้เริ่มที่ 100 พร้อมอธิบายได้ว่าช่วงเริ่มต้นคือเมื่อใด
- [ ] เกณฑ์ข้อมูลเก่า `staleAfterDays` สอดคล้องกับการใช้งาน และไม่ถูกเรียกว่าปฏิทิน SET

## นำเข้าและอัปเดต

- [ ] CSV ที่ผ่าน Data contract นำเข้าได้ และข้อมูลหลักอยู่ที่ `data/private/current.json`
- [ ] ไฟล์เกิน 1 MB, วันไม่ถูกต้อง, ราคาไม่เป็นบวก/ไม่ finite และ `(date,symbol)` ซ้ำ ถูกปฏิเสธ
- [ ] ไฟล์ผิดรูปแบบไม่แทนที่ข้อมูลหลักชุดที่ใช้งานได้อยู่
- [ ] รัน refresh ด้วยไฟล์เดิมซ้ำแล้วไม่เพิ่มข้อมูลซ้ำหรือเปลี่ยนวันที่ราคา
- [ ] เข้าใจว่าการเลือก CSV ในเบราว์เซอร์เป็น preview และไม่ใช่ CLI import ที่บันทึกข้อมูลหลัก
- [ ] ระบุแหล่งจริงและวิธี mapping ได้ ถ้าใช้ข้อมูลนอกชุด DEMO

## โค้ดและการส่งต่อ

- [ ] `npm test` ผ่าน หรือบันทึก failure ที่ยังแก้ไม่เสร็จอย่างชัดเจน
- [ ] `npm run check` ผ่าน และ `npm run doctor` ไม่รายงานปัญหาที่ทำให้เปิดใช้งานไม่ได้
- [ ] `git status --short` ไม่มีข้อมูล Efin ส่วนตัว token หรือไฟล์ที่ไม่ตั้งใจจะเผยแพร่
- [ ] การเปลี่ยนความต้องการอยู่ใน config/brief/กติกาโปรเจกต์ ไม่แก้ upstream Skills ทีละตัว
- [ ] ถ้าใช้ Skills ระบุชื่อที่มีจริง และไม่อ้างว่าเรียกใช้ทั้งที่เพียงอ่านแนวทาง
- [ ] ถ้าทำ scheduling ระบุสถานะว่าเป็นแผนหรือเปิดใช้งานจริง พร้อมหลักฐานหนึ่งรอบ
