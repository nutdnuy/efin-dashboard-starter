# ตรวจว่า Dashboard นี้ใช่สำหรับคุณหรือยัง

ใช้หลังได้ลองเวอร์ชันแรก ไม่ต้องตอบทั้งหมดก่อนเริ่มคุย

- เปิดหน้าแล้วตอบคำถามการลงทุนที่ตั้งไว้ใน BRIEF.md ได้หรือยัง
- สิ่งที่สำคัญที่สุดเห็นได้ทันทีไหม มีส่วนไหนแน่นหรือรบกวนสายตา
- ตัวกรอง ตาราง และการกดดูรายละเอียดทำงานตามที่ตกลงไหม
- อ่านบนอุปกรณ์ที่จะใช้จริงได้ไหม
- รู้ไหมว่าตัวเลขมาจากไหน เป็นข้อมูลวันที่เท่าไร และมีหน่วยอะไร
- ตัวเลขสำคัญอย่างน้อยหนึ่งค่าตรวจซ้ำกับต้นทางหรือการคำนวณอิสระแล้วหรือยัง
- ถ้าข้อมูลยังไม่มี โหลดไม่สำเร็จ หรือเก่า หน้าจอบอกให้เข้าใจไหม
- ปิดแล้วเปิดครั้งต่อไปตาม APP.md ได้จริงไหม

ถ้ายังไม่ถูกใจ บอกสิ่งที่อยากเปลี่ยนด้วยภาษาปกติ Agent ปรับต่อในโปรเจกต์เดิมและทดสอบส่วนที่เปลี่ยน
